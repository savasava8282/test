## Следующий безопасный шаг

Завершить текущую ограниченную задачу Codex:

1. Проверить SSH-аутентификацию с GitHub через существующий deploy key.
2. При недоступности SSH-порта 22 использовать `ssh.github.com` и порт 443.
3. Создать или подготовить отдельную локальную копию репозитория.
4. Создать в корне ровно:
   - `technical_spec.md`;
   - `roadmap.md`;
   - `rules.md`;
   - `current_status.md`;
   - `module_map.md`;
   - `start_prompt_for_next_chat.md`.
5. Не создавать `next_steps.md`.
6. Не создавать код приложения.
7. Проверить содержимое файлов и контрольные суммы.
8. Сделать commit и push через deploy key.
9. Вернуть commit hash и подробный отчёт без секретов.
10. После отчёта ChatGPT должен независимо проверить GitHub.
